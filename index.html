Encoding (marks and channels)
  • Detail — connected scatterplot: one dot per month; x = CBUAE base rate (%), y = monthly sales. Segments join consecutive months, so the line is the market’s path through time.
  • Line width = mortgage ratio (mortgages ÷ sales that month): thick when many loans sit behind each sale, thin as they fade. Colour = market phase or velocity.
  • Dashed grey arrow = schematic textbook expectation (higher rates → fewer sales). Pink rings = milestones.
  • Overview — stacked area: x = month, y = monthly count, colour = Sales / Mortgages / Gifts stacked, with the brush and a phase ribbon.
Interaction guide
  • Brush the overview or use the period buttons; releasing snaps to whole months with an elastic ease (d3.easeBackOut).
  • Play / Pause / Reset / Speed: replays the window month by month (0.5×, 1×, 2×); Reset restores everything.
  • Hover detail chart: flashlight lines project month to both axes & mark it on overview.
  • Guess first / Reveal reality: draw your expected path, then watch the real one.
  • Linking: broadcast on BroadcastChannel('rising-tide') as {from,to} month indexes.
